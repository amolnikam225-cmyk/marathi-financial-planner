मराठी Financial Planner – सुधारित आवृत्ती

या आवृत्तीत:
- सर्व नोंदींचा JSON Backup डाउनलोड
- JSON Backup मधून Restore (सध्याच्या नोंदी बदलल्या जातील; आधी Backup घ्या)
- ४ ते ६ अंकी PIN Lock सेट/बदल
- आधीच्या आवृत्तीतील नोंदींसाठी तोच स्थानिक डेटा key ठेवला आहे
- Service Worker cache आवृत्ती v2 केली आहे

GitHub Pages वर अपडेट करण्याची पद्धत:
1. जुनी Repository उघडा.
2. Add file > Upload files निवडा.
3. या ZIP मधील सर्व फाईल्स Repository च्या root मध्ये अपलोड करा.
4. जुन्या फाईल्स overwrite/replace करा आणि Commit changes करा.
5. 1-3 मिनिटे थांबा. मोबाईलवर Chrome मध्ये वेबसाइट उघडा आणि Refresh करा.
6. जुना कॅश दिसल्यास Chrome मध्ये वेबसाइटची Site settings > Storage मधील cache clear करा; मात्र Browser data clear करू नका, त्यामुळे नोंदी जाऊ शकतात. आधी Backup घ्या.

महत्त्वाची सुरक्षा सूचना:
PIN हा स्थानिक सोयीचा लॉक आहे; तो नोंदी एन्क्रिप्ट करत नाही. PIN विसरल्यास स्थानिक डेटा रीसेट करावा लागू शकतो. Backup फाईलमध्ये सर्व आर्थिक नोंदी असतात; ती सुरक्षित ठेवा.
