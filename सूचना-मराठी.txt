माझे आर्थिक नियोजन — Android Home Screen App

ही PWA (वेब अ‍ॅप) फाईल आहे; APK नाही. Home Screen वर Install करण्यासाठी फाईल HTTPS वेबसाइटवर प्रकाशित करावी लागेल.

1) या ZIP मधील सर्व फाईल्स एकाच फोल्डरमध्ये ठेवा.
2) index.html, manifest.webmanifest, sw.js आणि दोन्ही icon PNG फाईल्स एकाच ठिकाणी असाव्यात.
3) संपूर्ण फोल्डर HTTPS hosting वर प्रकाशित करा.
4) Realme मोबाईलवर Chrome मधून त्या HTTPS पत्त्यावर जा.
5) Chrome मेनू (तीन ठिपके) > Install app किंवा Add to Home screen निवडा.
6) पहिल्यांदा उघडताना इंटरनेट चालू ठेवा. नंतर सेवा-कर्मीमुळे अ‍ॅप ऑफलाइन उघडू शकते.

नोंदी या त्या ब्राउझरच्या local storage मध्येच राहतात. Browser data clear केल्यास नोंदी नष्ट होऊ शकतात; CSV नियमित डाउनलोड करा. दुसऱ्या मोबाईलवर आपोआप sync होत नाही.
